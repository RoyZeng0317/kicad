# Windows Hello IR 攝影機 — 專案架構與產品規格

## 一、產品概述

本產品為支援 Windows Hello 臉部辨識的 USB 紅外線（IR）攝影機，透過 IR LED 照明與近紅外線感光器實現臉部深度偵測，取代傳統 RGB 攝影機的安全性不足問題。

### 核心規格

| 參數 | 規格 |
|------|------|
| 解析度 | 1280×720 (HD) / 640×360 (Binning) |
| 幀率 | 30fps (HD) / 60fps (Binning) |
| IR 波長 | 850nm（隱蔽性佳） |
| 介面 | USB 2.0 Type-C |
| 電源 | USB 供電 5V / 500mA |
| 尺寸 | ≤ 50mm × 30mm × 25mm |
| 認證需求 | Windows Hello Face Authentication DDI |

## 五、電路模擬計畫

### 5.1 模擬工具分工

| 工具 | 負責模擬 | 原因 |
|------|----------|------|
| **TINA-TI** | TPS92515 LED 驅動、TPS54202 Buck | TI 官方模型最完整 |
| **LTspice** | AMS1117/TLV70012 LDO | ADI 模型精確 |
| **KiCad SPICE** | STM32 I2C 數位訊號、全系統 DC 分析 | 整合度高 |

### 5.2 模擬分析項目

#### A. TPS92515 LED 驅動（TINA-TI）

```
分析類型：瞬態分析 (Transient)
參數設定：
  - 輸入電壓：5V (USB)
  - 輸出電流：700mA (8顆 SFH 4259 串聯)
  - 開關頻率：~370kHz
  - 模擬時間：10ms
  
驗證項目：
  ✓ LED 電流漣波 ≤ 10%
  ✓ 效率 ≥ 85%
  ✓ 啟動時間 ≤ 5ms
  ✓ PWM 調光回應
```

#### B. TPS54202 Buck 降壓（TINA-TI）

```
分析類型：瞬態分析 + 穩態分析
參數設定：
  - 輸入電壓：5V (USB)
  - 輸出電壓：3.3V
  - 輸出電流：500mA max
  - 開關頻率：570kHz
  
驗證項目：
  ✓ 輸出電壓漣波 ≤ 30mV
  ✓ 負載瞬態回應 ≤ 100mV undershoot
  ✓ 效率 ≥ 90%
```

#### C. AMS1117 / TLV70012 LDO（LTspice）

```
分析類型：負載階躍分析 (Load Step)
參數設定：
  - 輸入電壓：3.3V
  - 輸出電壓：2.8V / 1.8V / 1.2V
  - 負載變化：1mA → 100mA (10ns 上升)
  
驗證項目：
  ✓ 輸出電壓偏差 ≤ 2%
  ✓ 恢復時間 ≤ 50µs
  ✓ PSRR ≥ 60dB @ 1kHz
```

#### D. 全系統 DC 分析（KiCad SPICE）

```
分析類型：DC 工作點分析
驗證項目：
  ✓ 各電源軌電壓正確
  ✓ 各 IC 電流消耗合理
  ✓ 總功耗 ≤ 2.5W (500mA @ 5V)
```
